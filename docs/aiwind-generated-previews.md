# AiWind-derived prompt previews

Ten images approved for the Studio gallery on 2026-09-22 were newly generated
with the built-in imagegen tool. No AiWind image was downloaded, edited or
used as an image reference. The CHINA food-typography image is the first card.

The text prompts were normalized from public entries on
<https://www.aiwind.org/>. The catalog retains the source entry title and
the author label displayed by that site. Author identities were not
independently verified; the source site is linked instead of guessing
individual profile URLs.

Reference-face instructions were replaced with fictional adults.
The food-typography template was filled with CHINA and Chinese dishes.
The croissant still life omits third-party fashion-brand labels.
The English field records the actual generation prompt; the Chinese field
is its localized equivalent. Model filters identify suggested Studio
targets, not the model used to create these previews.

`/studio-prompt-assets/prompt-library/images/` route. They do not use the
temporary user-upload bucket. The public source contains stable image URLs,
