# Prompt template

Use only the sections that help the request:

```text
Subject and action:
Environment and time:
Composition and framing:
Style and visual language:
Lighting and color:
Motion and camera (video only):
Text or brand constraints:
Negative constraints:
```

For a simple request, keep the output concise. Do not add a cinematic style, camera, or identity detail that the user did not want. If a parameter is unknown, label it as a suggestion rather than pretending it is required.
